# Garincha Group Mobile App

Мобильное приложение Garincha Group реализовано на **Expo/React Native** и покрывает ключевые сценарии, описанные в корневом `README.md` репозитория.

## Возможности
- Каталог предложений партнёров холдинга и карточка товара
- Управление корзиной и оформление заказа
- Личный кабинет участника клуба с настройкой профиля и уведомлений
- Раздел бонусной программы с историей операций и прогнозом начислений
- Авторизация участника и хранение данных в состоянии приложения

## Структура
```
mobile_app/
├── App.tsx                # Точка входа, подключение навигации
├── app.json               # Конфигурация Expo
├── package.json           # Скрипты и зависимости
├── src/
│   ├── components/        # Повторно используемые UI-компоненты
│   ├── constants/         # Цветовая палитра и константы
│   ├── navigation/        # Конфигурация навигации (стек, табы)
│   ├── screens/           # Экраны приложения
│   ├── services/          # Моковое API и работа с данными
│   └── store/             # Состояние приложения (Zustand)
└── README.md              # Документация по мобильному клиенту
```

## Подготовка окружения
1. Установите LTS-версию Node.js (18+) и npm.
2. Установите Expo CLI глобально (опционально):
   ```bash
   npm install -g expo-cli
   ```
3. Перейдите в каталог мобильного приложения и установите зависимости:
   ```bash
   cd mobile_app
   npm install
   ```

## Скрипты
- `npm run start` — запуск Expo Dev Server (выбор платформы через меню).
- `npm run android` — запуск в Android-эмуляторе или Expo Go на Android.
- `npm run ios` — запуск в iOS Simulator или Expo Go на iOS.
- `npm run web` — запуск web-версии приложения.
- `npm run lint` — проверка кода линтером.

## Переменные окружения
Приложение использует моковое API (`src/services/mockApi.ts`) и не требует дополнительных переменных окружения. Для подключения реального backend'a необходимо заменить методы в `mockApi` и, при необходимости, добавить конфигурацию (например, `.env`).

## Дополнительная информация
- Авторизация реализована проверкой email в домене `@example.com` и может быть адаптирована под реальный API.
- Состояние (каталог, корзина, бонусы) управляется через Zustand и легко расширяется для интеграции с REST/GraphQL.
- Для поддержки push-уведомлений и защищённого хранения токенов рекомендуем подключить `expo-notifications` и `expo-secure-store`.
