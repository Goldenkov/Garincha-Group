# Garincha Group

## Описание проекта

**Garincha Group** — головная организация группы компаний.  
Через веб-платформу и мобильные приложения вы сможете:

- Выбирать любого партнёра из холдинга и переходить на его сайт  
- Изучать раздел **«Партнёрство»**  
- Читать раздел **«О нас»**  
- Смотреть раздел **«Контакты»**  
- Просматривать раздел **«Вопросы и ответы»**  
- Пользоваться разделом **«Бонусная программа»** для участников клуба Garincha Group  

---

## Личный кабинет

В личном кабинете участники смогут:

- Просматривать и редактировать свои персональные данные  
- Отслеживать активность по партнёрским программам  
- Управлять подписками на новости и уведомления  
- Просматривать историю операций и бонусный баланс  
- Получать персональные предложения и акции

## Usage

### Запуск в Docker

```bash
# 1. Соберите образ
docker build -t garincha-group .

# 2. Запустите контейнер (порт 8000 хоста → 8000 в контейнере)
docker run -d --name garincha-group -p 8000:8000 garincha-group
```
